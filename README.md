# US Bikeshare Data Analysis

## Project Analysis

The application provides insights into bikeshare usage patterns, including popular travel times, commonly used stations, trip duration, and user information. These statistics help users understand how bikeshare services are used across different cities.
## Project Overview

This project analyzes bikeshare data from three major cities in the United States:

- New York City
- Chicago
- Washington

The Python program allows users to explore bikeshare data by selecting a city, month, and day of the week.

## Project Features

- Most frequently used month
- Most frequently used day of the week
- Most frequently used start hour
- Total travel time
- Average travel time
- Most popular start station
- Most popular end station
- Most common combination of start and end stations
- User type information
- Gender information
- Birth year information

## How to Use the Application

1. Run the Python program using `python bikeshare.py`.
2. Select a city when prompted.
3. Select a month or choose all months.
4. Select a day of the week or choose all days.
5. Review the bikeshare statistics displayed by the application.
